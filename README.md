# مقرأة الهدى الإلكترونية لتعليم القرآن الكريم
## MAQRAAT AL-HUDA — PREMIUM INSTITUTIONAL DIGITAL EXPERIENCE

موقع إلكتروني مؤسسي متكامل فائق الفخامة والاحترافية تم تصميمه وتطويره لصالح **مقرأة الهدى الإلكترونية لتعليم القرآن الكريم** وفقاً لوثيقة التصور العام الرسمية المعتمدة.

---

## 🌟 الميزات والمواصفات الرئيسية

### ١. الهوية البصرية ونظام التصميم (Design System)
- **الألوان المعتمدة**:
  - الأخضر الداكن الأساسي (Primary Forest Green): `#153D32`
  - العاجي الدافئ للخلفيات (Warm Ivory): `#F7F5EF`
  - الذهبي الوقور للّمسات (Muted Gold): `#B69A65`
  - المريمي الناعم (Soft Sage): `#E5ECE6`
  - الفحمي الداكن للنصوص (Dark Charcoal): `#28342F`
  - الأبيض النقي (Pure White): `#FFFFFF`
- **الخطوط الطباعية**:
  - `IBM Plex Sans Arabic` للواجهات والنصوص الأساسية
  - `Noto Naskh Arabic` / `Amiri` للآيات القرآنية الرصينة
- **الشعار الرسمي**: المحافظة التامة على الشعار الأصلي المعتمد واستخراجه بأعلى دقة.
- **الصور الفوتوغرافية**: استخدام الصورة المرجعية المعتمدة للمصحف الشريف على الحامل الخشبي مع الإضاءة الدافئة.

---

### ٢. بنية الموقع والصفحات العامة (Information Architecture)
1. **الصفحة الرئيسية (`/`)**:
   - الشريط العلوي الفاخر مع الشعار وروابط التنقل والزرين البارزين للتسجيل
   - واجهة ترحيبية سينمائية (Hero Section) مع خلفية المصحف الشريف المعتمدة
   - نبذة تعريفية (من نحن) وزر "اقرأ المزيد"
   - قسم الإحصائيات الحية المحدثة آلياً
   - جدول الحلقات القرآنية مع بطاقات المواعيد وتصفية المنصات (Zoom / Google Meet)
   - آراء وشهادات طالبات المقرأة مع إمكانية إرسال تقييم جديد
   - تذييل الموقع المؤسسي
2. **صفحة من نحن (`/about`)**: التعريف الشامل، الأهداف الستة المعتمدة، ورسالتنا وعبارتنا الإيمانية.
3. **صفحة رؤيتنا ورسالتنا (`/vision`)**: عرض تحريري راقٍ لرؤية المقرأة نحو آفاق أوسع في نشر كتاب الله.
4. **صفحة الإحصائيات (`/statistics`)**: تقرير تفصيلي مع توزيع المسجلات حسب الدول والمقارنات الإحصائية.
5. **صفحة المقرأة الإلكترونية (`/schedule`)**: متصفح الحلقات وتصفية المواعيد وحالة التسجيل.

---

### ٣. مسارات التسجيل الذكية (Registration Workflows)
- **مسار تسجيل الطالبات (`/register/student`)**:
  - التسجيل المباشر من بطاقة الحلقة المختارة دون الحاجة لإنشاء حساب مسبق
  - المرحلة الأولى: تعبئة البيانات (الاسم، الجوال، البريد، نوع الهوية، رقم الهوية، الجنسية، بلد ومدينة الإقامة، تاريخ الميلاد) مع إدراج الحلقة والمعلمة تلقائياً.
  - المرحلة الثانية: التعهد الصريح للطالبة والموافقة الإجبارية.
  - المرحلة الثالثة: تأكيد التسجيل الناجح وعرض رابط مجموعة الواتساب الخاصة بالحلقة (إن وجد).
  - تحديد تلقائي لفئة الطالبات (كبار / أطفال دون سن 16) لحساب الإحصائيات بدقة.
- **مسار تسجيل المعلمات والمشرفات (`/register/staff`)**:
  - التقديم إما كـ "معلمة" أو "مشرفة"
  - الإشعار الإلزامي بخصوص وزارة الشؤون الإسلامية والدعوة والإرشاد
  - الحقول الـ 23 كاملة متضمنة العنوان الوطني والوظيفة والمؤهل
  - رفع آمن لصورة التوقيع المعتمد مع تنبيه منصة أبشر والأدلة الجنائية
  - رفع صور وملفات الشهادات والمؤهلات العلمية وحفظها في التخزين المشفر
  - التعهد الخاص بالمعلمة أو المشرفة والموافقة عليه.

---

### ٤. لوحة التحكم الإدارية المحمية (`/admin`)
- **تسجيل الدخول الآمن (`/admin/login`)**:
  - بيانات الدخول الافتراضية: `admin` / `admin123`
  - جلسات مشفرة ومحمية بكوكيز HTTP-Only
- **الأقسام الإدارية**:
  - **لوحة التحكم العامة (`/admin`)**: متابعة المؤشرات والطلبات المقبولة والمعلقة وحالة الحلقات.
  - **إدارة طلبات الطالبات (`/admin/students`)**: البحث والتصفية، فحص البيانات، وقبول أو رفض الطلبات.
  - **إدارة طلبات المعلمات والمشرفات (`/admin/staff`)**: مراجعة الحقول الـ 23، معاينة صورة التوقيع والشهادات العلمية عبر بث مشفر، والاعتماد أو الرفض.
  - **إدارة الحلقات (`/admin/sessions`)**: إنشاء حلقات جديدة، تعديل المنصات (Zoom/Meet)، تحديد المواعيد، وتعيين روابط مجموعات الواتساب.
  - **إدارة الآراء والشهادات (`/admin/testimonials`)**: اعتماد نشر الآراء في الصفحة الرئيسية أو حجبها ومكافحة الرسائل المزعجة.
  - **سجل التدقيق والإعدادات (`/admin/settings`)**: سجل فوري (Audit Trail) لجميع العمليات الحساسة ومتابعة حالة الخوادم.

---

### ٥. قاعدة البيانات والأمان (Database & Security)
- **قاعدة البيانات الافتراضية**: محرك SQLite مدمج عالي الأداء مع دعم WAL mode بدون أي متطلبات تثبيت خارجية.
- **التوافق التام مع Supabase / PostgreSQL**: تم توفير ملف الترحيل الكامل `supabase/schema.sql` متضمناً:
  - تعريف الجداول والمفاتيح والفهارس
  - سياسات الأمان على مستوى الصفوف (Row Level Security - RLS)
  - الدالة الآمنة لاحتساب الإحصائيات العامة `get_public_institution_statistics()`
- **الخصوصية التامة**:
  - عدم كشف البيانات الشخصية للطالبات في الشاشات العامة أو الإحصائيات
  - حماية مسار المستندات (`/api/admin/files/...`) وقصره على الإدارة المصرحة
  - الفصل الدقيق بين الطلبات المقدمة وبين المقبولات فعلياً في الإحصائيات.

npm run dev

npm run build
